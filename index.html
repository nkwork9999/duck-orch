duckOrch

DuckDB上で依存関係を解決し、パーティションやデータ品質を管理するオーケストレーション拡張。

利用ガイドSQL リファレンス

クイックスタート

INSTALL duckorch FROM community;
LOAD duckorch;
PRAGMA orch_asset_list;

機能ガイド

DAGと増分実行タスク定義、依存解決、差分実行、テスト、リネージを確認します。アセット運用パーティション、バックフィル、センサー、動的アセット、データ取り込みを扱います。実行基盤とCLIスケジューリング、失敗時の扱い、メタデータの設計とコマンドを説明します。MCPと埋め込みMCPの利用手順と、アプリから呼び出す機能を掲載しています。
