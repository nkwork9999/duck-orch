DailyPartitionPlanner

Map application model IDs to registered daily assets on one connection.

  • __init__(self, connection: DuckDBPyConnection, models: Mapping[str, str])
  • pending(self, model_id: str, start: date, end: date) → list[date]

  • pending_ranges(self, model_id: str, start: date, end: date) → list[tuple[date, date]]

GenerationCoverage

Durable half-open work intervals on a host-owned, tenant-specific database.

  • __init__(self, connection: DuckDBPyConnection, models: Mapping[str, str])
  • enqueue(self, model_id: str, generation: str, requested: DateWindow) → list[CoverageClaim]

    Atomically reserve just the pieces not already queued or completed.

  • finish(self, claim: CoverageClaim, *, success: bool) → bool

    Keep successful coverage or release a failed reservation for retry.

  • batches(claims: list[CoverageClaim]) → list[CoverageBatch]

    Combine adjacent intervals from separate requests into one job.

ChangeWindowPlanner

Read-side change plan for a host-registered calendar DAG. The caller supplies a tenant-specific graph and retained date horizon at construction. Use ALL when an edge has no established partition mapping.

  • __init__(self, dependencies: Mapping[str, Mapping[str, PartitionGrain | RollingDependency]], horizon: DateWindow)
  • affected(self, source_id: str, changed: DateWindow) → dict[str, tuple[DateWindow, ...]]

    Propagate one changed window to downstream models in topological order.

  • affected_many(self, changes: Mapping[str, Iterable[DateWindow]]) → dict[str, tuple[DateWindow, ...]]

    Propagate disjoint source changes and merge touching output intervals.

  • explain(self, changes: Mapping[str, Iterable[DateWindow]], *, tenant_id: str, bytes_per_day: Mapping[str, int] | None=None) → Iterator[PlanStep]

    Stream source and parent-edge evidence in dependency order.
