DailyPartitionPlanner

Map application model IDs to registered daily assets on one connection.

  • __init__(self, connection: DuckDBPyConnection, models: Mapping[str, str])
  • pending(self, model_id: str, start: date, end: date) → list[date]

    Registered days in [start, end) whose latest attempt has not succeeded.

  • pending_ranges(self, model_id: str, start: date, end: date) → list[tuple[date, date]]

    Coalesce adjacent pending registered days into half-open ranges.

ChangeWindowPlanner

Read-side plan for one changed input in a host-registered calendar DAG. The caller supplies a tenant-specific graph and retained date horizon at construction. Use ALL when an edge has no established partition mapping.

  • __init__(self, dependencies: Mapping[str, Mapping[str, PartitionGrain]], horizon: DateWindow)
  • affected(self, source_id: str, changed: DateWindow) → dict[str, tuple[DateWindow, ...]]

    Propagate one changed window to downstream models in topological order.
